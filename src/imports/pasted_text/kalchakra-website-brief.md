Create a **production-ready futuristic racing championship website** called **KALCHAKRA — Multinational Championship**.

This is a Round 2 product build, not a static landing page. Transform the existing Kalchakra racing concept into a complete, professional, interactive championship platform that users can explore, understand, interact with, and act on.

Preserve the strongest visual identity of the existing design while improving the information architecture, usability, responsiveness, and interaction design.

## DESIGN DIRECTION

Create a premium futuristic motorsport aesthetic.

Visual character:

* Cinematic
* High-performance
* Futuristic
* Premium
* Minimal
* Editorial
* Professional sports platform
* Strong typography
* Large numerical statistics
* Technical data presentation
* Sharp geometric layouts
* Subtle glass surfaces

Avoid:

* Excessive neon
* Excessive gradients
* Visual clutter
* Generic F1 branding
